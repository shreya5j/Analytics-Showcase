# Multi-Channel E-commerce Analytics

## About the Project
Multi-Channel E-commerce Analytics is an Excel-based data analytics project focused on understanding sales performance, order trends, customer demographics, product categories, and e-commerce sales channels.

The project uses Microsoft Excel to transform raw sales data into meaningful business insights through data analysis, PivotTables, PivotCharts, and an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and Data Visualization

## Key Analysis
- Monthly Sales vs Orders
- Sales by Gender and State
- Order Status Distribution
- Age Group and Gender Analysis
- Orders by Sales Channel

## Key Features
- Interactive dashboard with Month, Channel, and Category slicers.
- Visual comparison of sales and order trends.
- Multiple charts to present business data clearly.

## Project Files
- `Multi_Channel_Ecommerce_Analytics.xlsx` — Excel workbook containing the dataset, analysis sheets, and dashboard.
- `screenshots/dashboard.png` — Dashboard preview.

## How to Use
1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard sheet and use the slicers to explore the data.
